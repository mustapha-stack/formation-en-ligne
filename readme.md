# 💻 Plateforme de formation en ligne

## 📖 Présentation du projet

Ce projet a été réalisé dans le cadre de mon apprentissage en développement informatique au **Collège Ahuntsic**.

Il s'agit d'une application web permettant aux utilisateurs de consulter un catalogue de formations et d'accéder aux informations détaillées de chaque formation.

Ce projet m'a permis de mettre en pratique les connaissances acquises durant ma formation, notamment en développement web, en programmation JavaScript et en manipulation de données JSON.

Déploiement en ligne

Le site est accessible à l'adresse suivante :

https://mustapha-stack.github.io/formation-en-ligne/


## 🛠️ Technologies utilisées

- **HTML5** : structure des pages web.
- **CSS3** : mise en forme et design de l'interface.
- **JavaScript** : fonctionnalités interactives et manipulation du DOM.
- **JSON** : stockage et organisation des données.
- **Fetch API** : récupération des données depuis un fichier JSON.

## ✨ Fonctionnalités

- Affichage dynamique des formations.
- Consultation des détails de chaque formation.
- Chargement des données depuis un fichier JSON.
- Navigation entre les différentes pages.
- Pagination du catalogue de formations.

## 📚 Objectifs pédagogiques

Ce projet m'a permis de développer mes compétences en :

- Développement Front-End.
- Programmation JavaScript.
- Manipulation du DOM.
- Utilisation de l'API Fetch.
- Manipulation des objets et tableaux JSON.
- Organisation et structuration d'un projet web.

## 🚀 Installation et utilisation

1. Cloner le dépôt :

   ```bash
   git clone URL_DE_VOTRE_DEPOT
   ```

2. Ouvrir le projet dans un éditeur de code.

3. Lancer le projet avec un serveur local, par exemple **Live Server** sur Visual Studio Code.

**Remarque :** L'utilisation d'un serveur local est nécessaire pour permettre le chargement des données JSON avec Fetch API.
